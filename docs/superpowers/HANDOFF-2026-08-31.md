## 2026-09-03 安全加固

- 匿名 capability 会话在登录用户首次继续时，于单会话锁内原子绑定到可信用户；绑定后匿名调用和其他用户的读、写、删除均返回 404。
- 同一 `session_id` 的历史读取、模型调用、输出验证和完整回合提交按 FIFO 串行；不同会话仍可并行。取消等待者不会泄漏锁。
- 会话按 `SESSION_TTL_SECONDS` 自动过期，历史限制为 `MAX_HISTORY_TURNS` 个完整回合，总活动会话限制为 `MAX_ACTIVE_SESSIONS`；容量满返回稳定 429，不驱逐仍活动的会话。
- 首次调用在 LLM 失败、空输出或取消时会删除新建的空会话；已有历史不会被失败调用污染。
- Spring 与 FastAPI 通过 `AI_PROXY_SECRET` 建立内部信任边界。FastAPI 使用 `hmac.compare_digest` 验证代理密钥；Spring 只传可信 `X-User-Id` 和代理密钥，不再向 FastAPI 转发浏览器 bearer token。
- 根 Compose 强制两个服务共享非空代理密钥；独立 Chatbot Compose 的 Chatbot、Redis、Chroma 端口只绑定 `127.0.0.1`，FastAPI 不再开放宽泛 CORS。
- Uvicorn 在 Dockerfile、`main.py`、bootstrap 和文档命令中禁用 access log。`main.py` 固定端口 8000 且不启用 reload。
- 普通与 stream 接口会把空模型输出安全映射为 503。`/chat/stream` 仍有意完整缓冲有界模型输出，以维持失败状态码和历史提交原子性，不改为逐 token 传输。
